# 1shot — приложение киберхауса

**Киберхаус 1shot · улица Мира, 37**

Telegram Mini App для выбора и бронирования игровых мест:

- карта клуба с основным залом, VIP-залом и PlayStation 5;
- просмотр доступности мест;
- выбор длительности бронирования;
- просмотр и отмена своих броней.

Оплата — на кассе при посещении. Интеграция с Gizmo требует настройки;
до подключения бэкенда в браузере доступен деморежим с примерными статусами.

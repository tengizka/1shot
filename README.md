# 1SHOT — Экосистема компьютерного клуба

Комплексное решение для компьютерного клуба 1SHOT: клиентский Telegram Mini App, приложение администратора 1SHOT Desk (Windows), облачный бэкенд на Supabase и инструменты управленческой аналитики.

## Структура репозитория

- 📱 **`miniapp/`** — клиентский Telegram Mini App: интерактивная карта зала клуба, бронирование ПК, адаптивная сетка без скролла, профиль гостя.
- 🖥️ **`desktop/`** — настольное приложение администратора 1SHOT Desk (Windows / PySide6): мониторинг ПК, управление бронями, очное подтверждение регистраций, сброс паролей, звуковые алерты и локальные напоминания.
- 📊 **`analytics/`** — управленческие и операционные отчеты клуба:
  - `Export-ClubAnalytics.py` / `Get-Analytics.ps1` — операционная аналитика и база спящих гостей (`1SHOT_Statistika_Club.xlsx`).
  - `Export-OwnerDashboard.py` / `Get-OwnerReport.ps1` — дашборд для собственников без лишней воды (`Otchet_Dlya_Vladeltsev.xlsx`).
- ⚙️ **`scripts/`** — автоматизация:
  - `Install-Desk.ps1` — автоустановка и обновление 1SHOT Desk на Windows.
  - `Import-ClubRota.ps1` — импорт графика смен администраторов.
  - `Apply-Supabase-Upgrade.py` — накат SQL-миграций на Supabase.
- ☁️ **`supabase/`** — Edge Functions (`club-auth`, `club-desk`, `club-bookings`, `club-agent`) и SQL-миграции базы данных.
- 📖 **`docs/`** — документация архитектуры и полная спецификация Gizmo 2.0 API (`docs.json`).
- 🧪 **`tests/`** — набор модульных (Python), поведенческих и UI-тестов (Playwright).
- 🚀 **`release/`** — staging и изолированные формы предрелизной регистрации.

## PS5 — только по телефону

В интерфейсе PS5 открывает контакты, а не бронирование. Для полного серверного
запрета примените `supabase/migrations/202609250005_ps5_phone_only.sql` в SQL Editor
и обновите Edge Function `reservations`. Перезапустите обновлённый agent.py:
он также отклоняет новые заявки мини-аппа на PS5. Уже созданные брони не отменяются;
ручное бронирование в Gizmo по звонку остаётся доступным.

Выбор ПК: VIP — 10 мест, STANDARD — две страницы по 10 мест. Кнопки страниц
не увеличивают приложение. Масштабирование и прокрутка карты удалены; тарифы
и профиль по-прежнему могут прокручиваться для чтения длинного содержимого.

## Шрифт и заставка

Интерфейс использует локальный variable-шрифт Unbounded (200–900), включая кириллицу.
Файлы и лицензия OFL находятся в `assets/fonts/`; Google Fonts при запуске не нужен.
SVG-заставка собирается из девяти летящих фрагментов исходного логотипа,
затем появляется подпись «КИБЕРХАУС». Переход в приложение ждёт окончания splashOut,
а не обрывает его таймером на 3.1 секунде. При prefers-reduced-motion заставка
пропускается; есть резервный таймер на случай отсутствия animationend.

## Club Desk — новая система (отдельно включаемая beta)

- Белый дождь символов и фрагментов логотипа, легенда с замком/ключом,
  30 ПК без PS5, счётчик свободных мест, разделители зон 100/200/300/400.
  На коротких экранах разделители заменяются компактными отметками на карточках,
  чтобы сохранить размер кнопок ≥44px и отсутствие прокрутки зала.
- `club-booking.js` / `.css`: две брони, колёса часов/минут, «1 час»,
  «Интервал», «Как пойдёт», мои брони и вход по коду присутствия.
- `desktop/`: Windows-панель + новый агент, трей, однократные звуковые уведомления,
  настраиваемые локальные напоминания,
  собственный журнал блокировок. Не создаёт native reservations в Gizmo.
- `supabase/migrations/202609250006_club_desk_beta.sql` и функции `club-bookings`,
  `club-agent`: выключенный по умолчанию backend. Старый агент не изменён.

**Не включайте новую систему только публикацией сайта.** Сначала прочитайте
[установку, переключение и восстановление](desktop/README.md).
Windows EXE собирается workflow **Build Windows Desk** или `desktop/build.ps1`.
Автотесты не заменяют проверку блокировки, входа и звука на реальном ПК клуба.

### Проверка компактного зала

`tests/hall-layout.cjs` проверяет 48 сочетаний размеров окна, страниц VIP/STANDARD
и свежих/устаревших статусов с видимой кнопкой «Мои брони · нет связи».
Проверяются пересечения карточек, границы карты/пагинации и размер кнопок ≥44px.
Большие разделители зон появляются только при достаточной высоте контейнера;
в компактном режиме используются две строки карточек с отметками начала зон.

### Свайпы по компьютерам

`hall-swipe.js`: единая последовательность VIP → STANDARD 1 → STANDARD 2.
Горизонтальный жест двигает только карточки; короткий/отменённый жест возвращает
их обратно, края не зацикливаются. Стрелки и вкладки используют тот же переход.
После свайпа не открывается случайная бронь. При reduced motion смена мгновенная.
`tests/hall-swipe.cjs` проверяет настоящие touch-события Chromium, включая
недоступные карточки, отмену жеста, короткий/вертикальный жест и обычный тап.

## Тестирование и проверка

```bash
# Тесты Python (Desk и логика управления)
python -m unittest discover -s tests -p "test_*.py"

# Регрессионные тесты интерфейса (Playwright)
node --test tests/*.test.cjs
```

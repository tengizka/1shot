# Обновление 1.2 → 1.3.0-beta

Нативные резервации Gizmo **не создаются**. По уточнению владельца клуба «Сегодня к…» — бронь в **1SHOT Desk**, ожидание **30 минут** после выбранного времени.

## Установка

1. Обновить исходники из ветки `arena/01a0d663-1shot`.
2. После уже установленных 006–009 выполнить **один раз целиком** в SQL Editor:
   `supabase/migrations/202609250010_arrival_time.sql`.
   Миграция не удаляет существующие брони и не меняет их сроки. Новые scheduled-заявки имеют шаг начала 5 минут и срок ожидания 30 минут; позднее время может перейти через полночь. Это не лимит оплаченной игры.
3. В CMD / PowerShell из `C:\1shot-source`:
   ```cmd
   npx.cmd supabase functions deploy club-agent --project-ref zqhfvtgktbfnxcclqqny --no-verify-jwt --use-api
   ```
   Остальные функции, секреты и `flow_version=2` остаются прежними. Не выключать `enabled`.
4. Штатно остановить старый Desk, распаковать **весь** архив 1.3 в новую папку. Сохранить `%LOCALAPPDATA%\1SHOT Desk\.env` и `desk.sqlite3`; не запускать два агента. Запустить новую программу и проверить обе связи.
5. Переоткрыть мини-апп в Telegram. Внизу профиля — `version 1.3.0`.

**GitHub push не обновляет Supabase и компьютер клуба.** До обновления агента мгновенный вход может ещё уведомлять и проходить через старое отображение holding. До миграции 010 старая версия клиента ещё может создавать брони для друга. Новый мини-апп уже посылает конец scheduled через 30 минут, но единая серверная проверка требует 010.

## Поведение

- «Сегодня к…»: только час и минуты 00/05/…/55. После выбранного времени ждём 30 минут, затем бронь истекает. Занятые ПК не бронируются. Нативных резерваций Gizmo по-прежнему нет.
- Мгновенный вход использует прежний защищённый журнал и краткую техническую блокировку, но на экране — «Подключаем…», не обычная бронь. Состояние holding для нового instant-пути пропущено. Уведомления о входе отключены и в SQL, и в агенте; проверки конкурирующей сессии, lease и запрет повтора неизвестного POST остаются. «Мгновенно» не означает нулевую сетевую задержку.
- В Desk мгновенные входы скрыты из списка броней, кроме `attention`: ошибки должны быть видимы для ручной проверки, но не звучать как новая бронь. Звуковые уведомления остаются для броней; заявки на пароль видны во вкладке аккаунтов без отдельного сигнала.
- Создание броней другу удалено. Уже существующие записи не стираются; в мини-аппе можно отменить старую такую бронь, но нет кнопки входа владельца на её ПК. Старый внутренний обработчик release сохранён для безопасного завершения ранее принятых операций.
- «Мои брони» в профиле, без истории и блока «Мои компьютеры». Это не удаление исторических строк из БД/журнала. Убраны успешные сообщения logout и служебный статус сервера. Ошибки операций не скрываются.
- Пароль в Desk можно сбросить после поиска по точному никнейму или номеру телефона. Телефон должен однозначно совпасть после удаления пробелов/скобок/дефисов; используйте международную запись как в Gizmo. Дубликаты телефонов не угадываются. Подтверждение личности и ограничения гостевых групп сохранены. `GUEST_USER_GROUP_ID` должен указывать на «Клиенты», а не неиспользуемую «Гости»; `18+` ищется по названию.
- Брони в Desk сортируются по времени, ПК или гостю, фильтруются по статусу / режиму. «Информация о госте» загружает из Gizmo имя, фамилию, никнейм, телефон и показывает идентификаторы; пароли и дата рождения не выдаются.
- Внешняя полоса прокрутки Windows скрыта, рабочая область при длинных списках прокручивается колёсиком / тачпадом. Контент не обрезается ради отсутствия полосы. Удалён нижний поясняющий текст.
- Тарифы: мягкий голубой STANDARD, розовый VIP, PS5 299 ₽ / час. PS5 по-прежнему только по телефону; карточка не меняет тарифы в самом Gizmo.
- Шесть локальных SVG-вариантов занятого ПК в центрированном компактном окне. Логотип анимируется внутри собственного блока, без разлёта символов. Графические стрелки, в том числе ↗, заменены на SVG, чтобы мобильная ОС не рисовала emoji-глифы.
- Закрытие брони свайпом — только за верхнюю ручку, вниз более 100 px с преимущественно вертикальным направлением. Колёса времени, короткие движения и выполняющаяся отправка не закрывают окно.
- Уменьшена лишняя перерисовка карт / списка Desk; опрос мини-аппа при скрытой вкладке пропускается; ограничено разрешение фонового canvas; учтён reduced motion. Нет гарантии одинакового FPS на всех телефонах — нужна проверка на реальных устройствах.

## Приёмка

На свободном тестовом ПК проверить мгновенный вход (нет звука, нет обычной карточки брони), обычную бронь (есть уведомление), scheduled c шагом 5 минут, ожидание 30 минут без выключения начатой игры. Проверить 23:55 → 00:25, отказ занятому ПК, остановку/перезапуск агента без повторного входа.

На iPhone/Android проверить кнопку «Забронировать» без прокрутки на портретном экране, осторожное закрытие за ручку, вращение колёс без закрытия, шесть SVG и локальную анимацию. В Windows проверить минимальное окно 900×600, доступность нижних настроек прокруткой, сортировку/фильтры/карточку гостя и поиск по телефону.

Старые attention-брони с несовпадающим журналом нельзя безопасно «починить» удалением SQLite. Кнопка отмены теперь видна и в Desk для этих статусов, но чужой/неподтверждённый замок агент не снимает: сначала ручная сверка Gizmo.

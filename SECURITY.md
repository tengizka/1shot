# Данные доступа и состояние очистки

Из актуального `agent.py` удалены встроенные адрес сервера, логин, пароль и `AGENT_SECRET`. Агент берёт настройки только из переменных окружения и при отсутствии обязательных значений прекращает запуск. Значения не приводятся в этом документе.

**Это не очистка истории GitHub и не отзыв опубликованных секретов.** Старые коммиты, другие ветки, клоны, форки, старые deployments и кэш могут содержать прежние значения. Нельзя считать их секретными после удаления из текущего файла.

## Что необходимо владельцу

1. Заменить опубликованный пароль учётной записи интеграции на сервере клуба и синхронно обновить его в локальных настройках агента.
2. Заменить опубликованный `AGENT_SECRET` в Supabase и локальном Desk в согласованное техническое окно. Учитывать незавершённые зашифрованные заявки авторизации, использующие этот ключ; не повторять неизвестные операции вслепую.
3. Согласовать очистку истории всех затронутых веток/тегов, старых артефактов и deployments. Для недоступных ссылок на коммиты/кэша может потребоваться GitHub Support. Перепись одной ветки не очищает весь репозиторий.
4. При необходимости ограничить доступ к репозиторию. Изменение видимости может повлиять на GitHub Pages в зависимости от тарифа; заранее обеспечить работу мини-аппа.

По запросу владельца история текущей ветки `arena/01a0d663-1shot` заменена одним корневым коммитом с очищенными файлами. Это **не удаляет** старые коммиты из других веток и хранилища GitHub. Ветки `main` и `arena/01a0b385-1shot` требуют отдельного удаления владельцем, если их история больше не нужна.

Ротация секретов, смена видимости, удаление других веток и очистка кэша GitHub **не выполнялись**. Старые SHA могут оставаться доступны даже после удаления ссылок; для полного удаления чувствительных данных нужен GitHub Support.

## Настройки

Desk продолжает читать `%LOCALAPPDATA%\1SHOT Desk\.env`; формат см. `desktop/env.example`. Не удалять `desk.sqlite3` ради очистки репозитория.

Если нужен старый `agent.py`, перед запуском задать `GIZMO_BASE_URL`, `GIZMO_LOGIN`, `GIZMO_PASSWORD`, `SUPABASE_URL`, `AGENT_SECRET` в окружении процесса. Он не загружает `.env` автоматически. TLS-проверка включена по умолчанию; для локального сервера с самоподписанным сертификатом предпочтительно настроить доверенный CA.

Не присылать пароли в чат, не добавлять реальные `.env`, дампы и журналы с персональными данными в Git. Названия переменных и общая спецификация API сами по себе не являются данными доступа.

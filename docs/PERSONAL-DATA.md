# Персональные данные (с 1 ноября 2026)

Сервер Supabase стоит в Ирландии (eu-west-1). Пока он не переехал в Россию, на нём **не храним ФИО, телефоны, почту и даты рождения гостей** (152-ФЗ, локализация).

## Что сделано

- **Регистрация только на ресепшене**: Desk → «+ Новый гость» → Gizmo в клубе. На сервер уходят только промокод и номер аккаунта Gizmo.
- **Мини-апп** (`registration-offline.js/.css`): кнопка «Нет аккаунта?» показывает, как зарегистрироваться в клубе (со словом промокода из `start_param`). Анкета `form-register` не открывается. На экране аккаунта поля имени, фамилии, почты, телефона и даты рождения скрыты и не отправляются (`disabled`).
- **База** (`migrations/202611010035_pd_minimize.sql`):
  - `club_registration_submit` отклоняет онлайн-анкеты;
  - триггер `profiles_strip_names` обнуляет `first_name/last_name`;
  - триггер `club_accounts_strip_pd` вырезает из `club_accounts.data` поля `firstName, lastName, email, mobilePhone, birthDate`;
  - уже сохранённые копии стёрты.
- **Лендинг** не ведёт в бота: гость называет кодовое слово на ресепшене.

## Правила для новых изменений

- Не возвращать онлайн-анкету и не сохранять на сервере ФИО, телефон, почту, дату рождения, пока сервер не в РФ.
- Имя показывать из Telegram (`initData`), не сохраняя.
- Менять личные данные гостя — только в клубе (Desk/Gizmo).

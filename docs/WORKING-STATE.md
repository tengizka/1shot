## Этот этап: стабильность Desk

- Карточки броней обновляются по ID: меняются только затронутые текстовые узлы, исчезнувшие карточки удаляются. Неизменённые карточки не пересоздаются при появлении/обновлении другой брони.
- Открытые сведения о госте и полученные сведения сохраняются при обновлениях; смена связанного аккаунта сбрасывает кэш личности. Устаревший ответ по прежней личности не применяется.
- Кнопки ПК сохраняют DOM-узлы; обновляется только изменившийся статус.
- Очередь сброса пароля сохраняет карточки по ID, включая состояние выполняющегося действия и его сообщения.
- Сохранение фокуса, курсора, результатов поиска и выделения при обновлении несвязанных данных проверено браузерным тестом. Изменение самого выделенного текста, удаление объекта или выбранная пользователем пересортировка не гарантируют сохранение выделения.
- Обычный текст в Desk выделяется; есть копирование телефона и номера брони. Если Clipboard API запрещён средой, показывается предложение выделить текст и нажать Ctrl+C. Скрытые пароли не извлекаются.
- Исправлен PowerShell build.ps1: admin-tools.js включён в локальную сборку, как в Windows CI.
- Мини-апп, SQL, функции Supabase, права и политика паролей этим этапом не меняются. Закрытие окна в трей сохранено.

## Уведомления Desk — следующий блок 2026-10-08

- Убраны UI «Увидел», «Тишина на 5 минут» и настройка периодического повторения. Операционные подтверждения/отмена брони не удалены. Старые bridge-методы оставлены для совместимости, но новый интерфейс их не вызывает.
- NotificationGate сохраняет монотонный notice_cursor в существующей SQLite **до** звука/tray. Повторный снимок/перезапуск не воспроизводит тот же event; старые локальные alerts/event_cursor при обновлении принимаются как уже показанные. Новые события одного ответа группируются в один сигнал без звуковой очереди. Выключенный звук тоже продвигает cursor, поэтому включение не создаёт отложенный шквал.
- Это гарантия at-most-once на данном локальном журнале, НЕ exactly-once: сбой между записью cursor и звуком может пропустить уведомление. Другие установки Desk с отдельными SQLite не координируются этим механизмом. Операционный журнал и бронь не изменяются/не удаляются.
- Визуальные карточки последних пяти событий остаются при выключенном звуке. Их прочтение не является условием работы.
- 12 локально синтезируемых сигналов, громкость, выбор отдельно для created/waiting/attention, ручное прослушивание каждого вида. Это НЕ нейронная речь. Голос, пользовательские напоминания и общий редизайн настроек ещё не завершены.
- Локально: 127 Python-тестов PASS (включая 4 новых notification/sound tests); Desk, admin-tools, stability, staged guest-passwords/registration browser suites PASS. Новый UI-тест проверяет 12 вариантов, выбор по событию и отсутствие старых read/mute/repeat-кнопок.

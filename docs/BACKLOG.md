# Отложено на потом

## Статистика рекламы в Google Таблицах
- Тенгиз создаёт пустую Google Таблицу и присылает ссылку (создавать таблицы коннектор не умеет, заполнять — умеет).
- Листы: сводка по площадкам (анкеты, подтвердили, не пришли, выдано часов, пришли повторно, траты после бесплатного часа, бюджет, цена гостя); новые гости; не пришли (заполнили анкету по промокоду, но не явились — с именем и ником из анкеты); бюджеты.
- Тенгиз присылает суммы по рекламе по площадкам → вписать и назвать цену одного гостя.
- Траты и визиты знает только Gizmo в клубе: Desk раз в день отправляет на сервер сводку по гостям из промокодов (визиты, траты, без паролей), из облака переносим в таблицу.
- Анкета, по которой гость не пришёл, живёт месяц (см. миграцию 021), потом удаляется.

## Заказ снеков из мини-приложения
- Заказывать можно только гостю, который сейчас сидит за ПК.
- Часть напитков админы отменяют и пробивают заново, чтобы отсканировать QR «Честного знака», поэтому гостю никогда не показываем «заказ отменён» — только «закрыт».
- API Gizmo v1 не умеет класть заказ в очередь клиентских заказов: `POST users/{id}/order/{product}/invoice` сразу создаёт чек со способом оплаты по умолчанию. Деньги через API не трогаем.
- Ждёт решения Тенгиза: схема заказа и оплата (см. переписку).
